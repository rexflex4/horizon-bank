# Crimson Horizon Bank — Digital Banking & Admin CMS

A multi-file online banking web application with customer Sign Up & Login, a 3D interactive Customer Dashboard, and a separate password-protected Admin Control Center.

## Files
- `index.html` + `js/public.js` — Public banking website (no admin links exposed)
- `auth.html` + `js/auth.js` — Customer Sign Up & Client Login
- `dashboard.html` + `js/dashboard.js` — Protected 3D customer banking dashboard
- `admin.html` + `js/admin.js` — Separate Admin Panel (templates, hero, contact, insights, rates, customer accounts)
- `css/styles.css` — Shared Crimson Horizon theme and 3D card styling
- `js/store.js` — Shared `localStorage` CMS & customer account store
